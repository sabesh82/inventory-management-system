# 🌿 Siddha Medicine Lab Inventory Management System

A streamlined inventory management system built for Siddha medicine labs to easily **add**, **edit**, and **delete** stock items, with secure **user authentication** and **real-time email alerts** when item quantities drop below defined thresholds.

Built using **Next.js**, **React**, **MongoDB**, and **Prisma**, this app ensures your traditional herbal stock is digitally tracked with minimal effort and maximum reliability.

---

## ✅ Features

- 🔐 **Secure Authentication** (Login system)
- ➕ **Add New Inventory Items**
- ✏️ **Edit Existing Item Details**
- ❌ **Delete Inventory Items**
- 📉 **Low Stock Alert Emails** sent to the dealer in real-time
- 📦 Simple and Clean UI for managing stock


